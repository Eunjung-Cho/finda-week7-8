# 8주차 Day 3 사전 준비 가이드: OpenDART API 키 발급 + GCP 프로젝트 점검

> Day 3(일요일) 수업 전까지 **반드시** 마쳐야 하는 두 가지입니다. 합쳐서 10분이면 됩니다. 이걸 안 해 오면 일요일 실습을 통째로 구경만 하게 됩니다 — 막히면 수업 전에 미리 연락 주세요.

## 준비 1. OpenDART API 키 발급 (5분, 무료)

일요일에 우리는 금융감독원 전자공시(DART)에서 기업 재무제표를 직접 수집합니다. 그러려면 본인 명의의 무료 API 키가 필요합니다.

- (1) https://opendart.fss.or.kr 접속 → 우측 상단 **"인증키 신청/관리"**
- (2) 회원가입 (이메일 인증)
- (3) 로그인 후 **인증키 신청** — 사용 목적은 "학습/연구"로 간단히 적으면 됩니다
- (4) 발급된 키(영문+숫자 40자)를 메일 또는 마이페이지에서 확인

인증키 신청 화면은 이렇게 생겼습니다 — 이메일은 본인 것을 넣고, 사용자 구분 **개인** / API 사용환경 **웹** / API 사용용도 **학습/연구**로 채우면 됩니다 (확인 URL은 비워도 됩니다).

![스크린샷](../assets/images/dart-signup-form-example.png)

**발급 확인 테스트**: 브라우저 주소창에 아래를 붙여넣고(키 부분만 교체) 실행하세요.

```
https://opendart.fss.or.kr/api/company.json?crtfc_key=본인키&corp_code=00126380
```

`"status":"000"`과 함께 삼성전자 정보가 보이면 성공입니다. `"010"` 또는 `"011"`이 보이면 키가 아직 활성화되지 않은 것 — 몇 분 뒤 다시 시도하고, 그래도 안 되면 캡처해서 연락 주세요.

주의 두 가지:

- (1) 키는 **비밀번호처럼** 다루세요. 노트북(Colab)을 공유할 때 키가 박힌 채로 공유하지 않기 — 일요일에 안전한 보관 패턴을 알려드립니다.
- (2) 무료 한도는 하루 20,000건 — 수업 용도로는 사실상 무제한이니 걱정하지 않아도 됩니다.

## 준비 2. GCP 프로젝트 점검 (3분)

일요일에는 7주차처럼 강사 데이터를 "읽기만" 하는 게 아니라, **본인 프로젝트에 테이블을 만듭니다.** 본인 프로젝트가 살아 있는지 지금 확인하세요.

- (1) https://console.cloud.google.com/bigquery 접속
- (2) 상단 프로젝트 선택기에서 **본인 프로젝트**(7주차 첫날 만든 것)를 선택
- (3) 쿼리 편집기에서 아래 1줄을 실행

```sql
SELECT 1 AS ok
```

- (4) 결과에 `ok = 1`이 나오면 통과입니다. 프로젝트가 없거나 오류가 나면 **수업 전에** 연락 주세요 — 수업 중에 계정 문제를 풀기 시작하면 그날 실습을 놓칩니다.

> 📷 스크린샷 추가 예정: (프로젝트 선택기와 확인 쿼리 결과 화면)

## 문제가 있을 때

- (1) DART 키 발급이 안 됨 → 가입 화면 캡처와 함께 연락. 일요일에는 예비용 샘플 데이터(플랜 B)로 실습할 수 있게 준비해 두었지만, 본인 키로 하는 것이 훨씬 남는 경험입니다.
- (2) GCP 프로젝트 문제 → 연락 주시면 임시 실습 공간(강사 프로젝트 내 개인 데이터셋)을 만들어 드립니다.
