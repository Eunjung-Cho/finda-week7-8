### 강사 메모 (수강생 배포 전 확인)

- 컨텍스트 문서 5.4의 "BigQuery 첫걸음"과 "SQL Server vs BigQuery" 프레이밍은 7주차부터 BigQuery를 사용해 온 실제 진행에 맞춰 "BigQuery 다시 보기"로, "PaySim을 BigQuery에 적재 데모"는 Day 2에서 이미 적재를 마쳤으므로 "비용 관점 재실행 데모"로 조정함
- 수업 전에 `crypto_bitcoin.transactions`의 세부정보 탭에서 파티션 컬럼(블록 타임스탬프 월 기준으로 알려짐), 테이블 크기, 행 수를 직접 확인하고, 실습 1과 실습 2의 미리보기 빈칸에 대한 강사 기준값을 미리 기록해 둘 것
- 실습 2의 기준 월("2025-01-01")은 수업 시점에 데이터가 확실히 존재하는 최근 월로 조정 가능 (공개 테이블 갱신 지연 확인)
- 과금 단가(약 $6.25/TiB)와 무료 한도(월 1TiB 쿼리, 10GB 저장)는 수업 전 요금 문서에서 재확인
- 할당량 설정 화면과 쿼리 설정 화면의 UI 명칭은 콘솔 업데이트로 바뀔 수 있으므로 스크린샷 촬영 시점 기준으로 본문 문구 대조
- 세션 3-3의 PaySim 테이블 이름(`paysim.transactions`)이 Day 2 자료의 실제 테이블 이름과 일치하는지 확인 후 필요시 교체
- "과제 안내문(별도 배포 문서)" 자리에 실제 8주차 과제 안내문 파일 링크 연결
- 40명이 실습 2의 버전 (2)를 각자 실행하는 것은 개인 프로젝트별 과금이므로 문제없으나, 버전 (1)과 (3)을 실수로 실행하는 학생이 나올 수 있음 — 세션 3-1의 최대 청구 바이트 설정(10 GiB)을 전원 완료했는지 실습 2 시작 전에 한 번 더 구두 확인
- 스크린샷 플레이스홀더 4곳 (쿼리 설정, 할당량 페이지, 미리보기 표시, 처리된 바이트 표시) 촬영 후 삽입
