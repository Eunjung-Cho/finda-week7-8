### 강사 메모 (수강생 배포 전 확인)

- (1) **설계 취지 (컨텍스트 문서 6.1)**: Day 1은 의도적으로 느립니다. 심화반이라도 도메인 이해와 스키마 파악 없이 쿼리부터 짜면 헛것을 추출하므로, 진도 압박이 있어도 1교시 도입부와 3교시 품질 이슈 발견 실습의 "직접 부딪히는 시간"을 줄이지 말 것.
- (2) **환경 조정 사항**: 컨텍스트 문서 4.2에는 Day 1 환경이 SQL Server 또는 PostgreSQL로 되어 있으나, 이미 배포된 적재 가이드가 Day 1부터 BigQuery 기준이므로 본 강의안은 전 과정 BigQuery(Standard SQL)로 통일해 작성함. 3교시 인덱스 토론도 "BigQuery엔 인덱스가 없다 → 파티셔닝"으로 조정함.
- (3) **사전 확인이 필요한 값**: (a) users와 cards의 적재 후 실제 컬럼명 (자동 감지 결과가 이 문서의 권장 컬럼명과 다르면 쿼리 수정 필요), (b) 거래 기간 MIN/MAX 실제 값, (c) is_fraud 비율, 음수와 0원 거래 건수, errors 값 목록 — 수업 전 강사 프로젝트에서 전체 쿼리를 한 번 실행해 결과를 확보해 둘 것.
- (4) **준비물**: Day 2 사전 과제용 JOIN 복습 워크시트는 [JOIN 복습 워크시트](day2-join-worksheet.md)로 이미 제작되어 있음 (컨텍스트 문서 6.1의 요구사항) — Day 1 수업 종료 직후 배포할 것. ERD 미니 실습용 화이트보드 툴 링크 또는 종이.
- (5) **시간 운영**: 세션 합계 170분 + 쉬는 시간 10분 = 180분. 쉬는 시간을 1-2교시 사이와 2-3교시 사이 5분씩 나누거나, 적재가 늦은 수강생 지원 시간으로 활용.
- (6) 스크린샷 플레이스홀더 2곳(Schema 탭, 처리 바이트 표시) 캡처 후 삽입할 것.
