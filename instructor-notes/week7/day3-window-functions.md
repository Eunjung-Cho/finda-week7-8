### 강사 메모 (수강생 배포 전 확인)

- 환경 조정: 컨텍스트 문서 4.2에는 SQL Server 또는 PostgreSQL로 되어 있으나, Day 1 배포 가이드가 BigQuery 적재 기준이므로 본 강의안의 모든 SQL을 BigQuery Standard SQL로 통일함 (DATEFROMPARTS → DATE(y, m, d), DATEDIFF → DATE_DIFF 등).
- Day 2 산출물 의존: 실습 2와 미니 프로젝트 R2는 `mcc_map` 룩업 테이블(Day 2 제작)을 전제로 함. Day 2 결석자를 위해 `mcc_map` 생성 스크립트(INSERT 문 버전)를 수업 전 공지방에 다시 배포할 것.
- 사전 실행 확인 필요: (1) 데이터셋 전체 마지막 거래일(anchor 값) 실제 확인 (실습 4의 휴면 인원 수가 극단적이지 않은지), (2) 미니 프로젝트 R1과 R2 모범 결과를 사전 실행해 스크린샷 캡처, (3) `users.current_age`와 `gender` 실제 컬럼명이 적재본과 일치하는지 (자동 감지 적재 시 컬럼명이 다를 수 있음 — Day 1 가이드 참고).
- 시간 리스크: 세션 3-1 실습 2(QUALIFY 포함)가 밀리면 QUALIFY는 "지름길 소개"로 1분 만에 넘기고 인라인 뷰 패턴만 확실히 다룰 것.
- 미니 프로젝트 모범답안(R1~R4 완성 쿼리)은 강사용 별도 파일로 준비 필요 (수강생 배포는 과제 마감 후).
- 6.4 연결 확인: 회고 질문("이걸 어떻게 발전시켜 최종 프로젝트로?")을 세션 3-3 마지막 5분에 배치했음. 발표 없이 각자 기록만 하고 마치는 형식이므로 시간 초과 위험 낮음.
